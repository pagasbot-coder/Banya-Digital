# Ш-01. One-pager платформы

| | |
|--|--|
| **Кому** | Eco / wellness и сети 3–4★. Гость, которому важен мягкий уход |
| **Обещание** | Мягкий уход. Понятная натуральность. Важны и гость, и документы |
| **Чем доказываем** | Состав в границах · бумаги Travel+ · ощущение в номере · один поставщик · русский пересказ на этикетке |
| **Чем не являемся** | Не самые дешёвые · не «органик» без бумаг · не копия Natura Siberica · не «как ЕТС» · не Fleur / Aquatique / La Nuit |
| **Характер** | Спокойный, честный, заботливый |
| **Место рядом с другими** | Hotel Line = цена · Fleur / Aquatique / La Nuit = дизайн и аромат · Natural = натуральность и бумаги |
| **Против ЕТС** | Ощущение и пакет, не война цен |
| **Origin** | Пока не зафиксирован - не говорим «российское» и «своё производство» |

## BrandScript (кратко)

**Закупщик:** герой = eco/wellness закупщик · проводник = Travel+ Natural · план = сегмент → образец + бумаги → пилот.  
**Гость:** после дороги → мягче, чем ждал · понятная натуральность на этикетке.
