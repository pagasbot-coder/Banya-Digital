# СЛАЙД 6. Границы до рынка (DoD этапа 2)

**На слайде:**  
Пока красное — витрину не открываем:  

□ Метод + % натуральности  
□ Пакет как на HL/Fleur + лист Natural  
□ Origin зафиксирован (без выдуманного «RU»)  
□ Слепой тест запаха с гостями  
□ Этикетка «простыми словами»  
□ COGS / коридор цены  
□ Lead time / MOQ  

На старте: без COSMOS, если знака нет — честно.  

**Говорить (~50 сек):**  
«Главный риск — написать Natural раньше продукта. Пульт фиксирует DoD: без процента, пакета, origin и теста продаж не стартуют.»

# СЛАЙД 8. Поле: возражения и риски

**На слайде:**  
Возражения (коротко):  
· COSMOS обязателен → Natural в это КП не ставим  
· «Natural по цене HL» → нет  
· СТМ / наш лого → отдельный проект, не Natural с другим лого  
· «Где произведено?» → только зафиксированный origin  

Реестр рисков — один лист для продаж (14 пунктов в пульте).  

**Говорить (~40 сек):**  
«СТМ не маскируем под Natural. Тендер с обязательным знаком без знака — не лезем. Иначе съедим и маржу, и доверие.»

# СЛАЙД 9. Пилот: успех, провал, выход

**На слайде:**  
Успех: 3 клиента · повтор ≥2/3 · мягкость и ощущение натуральности ≥70% · HL цел  

Провал: повтор <2/3 или метрики <60% → стоп масштаб  

Возврат: диагноз бренд-менеджера за 2 недели → ветка (сенсорика / бумаги / этикетка / коммерция)  

Второй круг снова провален → **линейку закрываем** (бренд + Human)  

*Цифры сценария — учебный пример, не отчёт завода.*  

**Говорить (~45 сек):**  
«Есть не только порог провала, но и точка выхода: два круга без успеха — закрываем, не крутим вечно.»
