## TL;DR

1. **Док. 2 v1.14 готов как рамка для собеса и dogfood.** Этапы 0-2 = факт/правила; 3-6 = учебный сценарий; раздел L + глоссарий ВЭД закрывают дыру «Китай молчит».
2. **Не live GTM.** Пока DoD этапа 2 красный (технолог), в рынок и в КП не идём. Это сила документа, не слабость.
3. **Внедрение в Quiet Partner:** не новый продукт. Третий режим `/brand` рядом с `/stages` и `/radar`. Волны: A markdown → B UI → C связки (China checklist). Код только после Go Human на волну B.
4. **Презентация собеса** пересобрана под v1.14, формат **горизонтальный 16:9**, двухколоночная вёрстка.

## 3) Вариант внедрения в наш проект (Quiet Partner)

Цель: пульт бренда - **личная мышца** бренд-менеджера / продакта (как ProjectM для РП), не waitlist-фича.

### 3.1 Волны

| Волна | Что | Критерий готовности |
|-------|-----|---------------------|
| **0 (сделано)** | Док. 1 + док. 2 v1.14 в KB | Human читает без пояснений |
| **A - markdown** | Папка `brand-pult/` (или Desktop): копия этапов + реестры MVP + Natural | 1 прогон 30-60 мин без кода |
| **B - `/brand` в QP** | UI-клон `/stages`, demo Natural, MD export | Dogfood 3×10 мин, refresh ок |
| **C - связки** | Чеклист China в этапе 2/4; мелкая ссылка на hub | Sales берёт ш-03 без бренд-менеджера в звонке |

### 3.2 Место в продукте

```text
/stages   - Пульт этапов (PM)
/radar    - Тихий напарник   [не трогаем в этом треке]
/brand    - Пульт бренда     [волна B]
```

### 3.3 MVP в UI (из док. 2)

**Этапы:** 0-6 как в пульте (3-6 с плашкой «сценарий»).  
**Реестры MVP:** аудитория · конкуренты · платформа · ассортимент · решения · не знаем · риски бренда.  
**Блок China:** чеклист L.5/L.6/L.9 (не отдельный продукт).  
**Demo:** Travel+ Natural из v1.14; поля %/origin/COGS = «открыто».
