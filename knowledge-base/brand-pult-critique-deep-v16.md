## Вердикт на одну страницу

Рамка бренда и процесс пульта — **зрелые для discovery и собеса**. Документ честнее типичного «GTM на фантазии»: есть анти-каннибализация, честные сертификаты, слепой тест, порог провала.

Главный системный дефект: **обещание в платформе уже жёстче, чем факты в пульте**. Платформа пишет «российское производство» и «свой контур»; пульт в «Не знаем» держит завод / Китай / гибрид. Это не стилистика — это удар по ценности №1 (честность). Пока контур производства и метод % не зафиксированы, Natural остаётся **намеренной позицией без продукта**.

Второй дефект: **учебный сценарий 3–6 выглядит как отчёт**. Цифры 78% / 71% / «лён победил» будут цитироваться как факт на собесе и в КП, если не отделить визуально и процедурно.

| Роль | Рамка | Доказанность | Готовность к рынку | Главный вердикт |
|------|-------|--------------|--------------------|-----------------|
| Brand Manager | 8.5/10 | 4/10 | 3/10 | Не продавать. Сначала снять противоречие «RU vs Китай» и операционализировать натуральность |
| Отраслевой эксперт | 7/10 | 3.5/10 | 2.5/10 | На тендере сети проиграете ЕТС/NS без заводских бумаг, SLA и происхождения |
| Product Manager | 8/10 процесс | 5/10 delivery | 2/10 ship | Нет DoD этапа 2 = нет права открывать этап 3 |

**Рекомендация стола:** принять разбор → **v1.7 только P0** → копирайтер → Human. Живой GTM, `/brand` в коде и обещания коммерции — **после DoD этапа 2**. Сценарий 3–6 не трогать как «план завода».

# 1. Brand Manager — досконально

## 1.1 Что держит ДНК

1. Порядок **разведка → платформа → оффер → рынок** соблюдён (playbook).  
2. Обещание и антипозиция согласованы с платформой: между HL и NS, не копия NS, не дешёвка.  
3. Характер (спокойный, честный, заботливый) спущен в бриф упаковки и в первую фразу питча.  
4. Правило этикетки «простыми словами» защищает Caregiver от пустого eco-театра.  
5. Сегмент vs Hotel Line — архитектура, не только скидка.  
6. Порог провала пилота — редкость; бренд-менеджер обычно давит на «ещё чуть дожать рынок».

## 1.2 Проверка по каркасу «ДНК бренда»

| Блок ДНК | В пульте | Оценка | Зазор |
|----------|----------|--------|-------|
| Сущность / миссия | Есть в духе платформы | OK | В one-pager миссия сжата до обещания — нормально для пульта |
| Ценности (4) | Честность, мягкость, практичность явны | Частично | Ценность «меньше пластика / диспенсер» в платформе есть, в примере почти отложена без правила «когда говорим об eco-пластике» |
| Двойной insight | Гость + закупщик | OK | — |
| Обещание | Совпадает с платформой | OK по тексту | Слабо по доказательствам |
| Философия | Есть косвенно | Слабо | Нет явной строки «не стикер, а состав+ощущение+бумага» в one-pager |
| Позиционирование | Сегмент + этаж цены | **Слом** | «Российское производство» в платформе vs неизвестный контур в пульте |
| Личность / архетип | Caregiver слышен в питче | OK | В возражениях тон иногда «продажный отказ» без заботы (нормируемо) |
| Антипозиция | Есть | OK | Слабая отстройка от **Fleur / Aquatique / La Nuit** |
| Доказательства 3+1 | Список | Слабо | Нет артефактов (макет, протокол, PDF-пакет) |
| ToV | В целом | OK | Риск тендера с обязательным знаком (давление соврать) |
| Айдентика | Бриф есть | OK для этапа 2 | Нет иерархии Travel+ / Natural на этикетке из платформы §8 |
| KPI | Есть + провал | OK как рамка | Гостевой «натурально» методологически дырявый (см. B7) |

## 1.3 Критика по пунктам

### B1. Операционализация «понятной натуральности» (P0)

«Минимальный %» без метода — пустой чеклист. Варианты рынка: ISO 16128, внутренняя норма завода, «маркетинговый %». Без выбора методa:

- технолог принесёт цифру, которую нельзя поставить рядом с ЕТС/COSMOS;  
- этикетка и скрипт разъедутся;  
- ценность «честность» станет декларацией о намерениях.

**Сделать в v1.7:** в §2.1 строка: «Метод: выбираем с технологом до фиксации % (кандидаты: …). До выбора % на этикетку и в КП не ставим.»

### B2. Противоречие происхождения (P0) — **новый жёсткий флаг**

Платформа: «…и российского производства.»  
Пульт: «Свой завод, Китай или вместе — не знаем.»

Для Natural это хуже отсутствия COSMOS. COSMOS — дорогой знак. Origin — базовый вопрос eco-отеля. Сейчас бренд **уже обещает** то, чего пульт не подтверждает.

**Сделать:**  
1) В платформе убрать/заменить «российское производство» на «контур уточняем; до фиксации не обещаем RU».  
2) В пульте §2.1: происхождение формулы и фасовки — часть границ обещания.  
3) В скрипте закупщику: запрет фраз «своё производство / сделано в РФ», пока контур не подписан.

### B3. Доказательства = список намерений (P0)

One-pager перечисляет состав · документы · ощущение · пакет. Нет ни одного проверяемого артефакта. Для этапа 2 это нормально **только** если шапка орёт: «Рамка. Не GTM. Не КП.»

**Сделать:** шапка + чеклист артефактов до этапа 3 (макет этикетки, протокол слепого теста, PDF-пакет как у HL, черновик «простыми словами»).

### B4. Архитектура дома обрезана (P1)

Fleur / Aquatique / La Nuit в платформе есть, в примере почти нет. Закупщик сети: «Чем Natural не Fleur?» Без ответа Natural начнут продавать «красивым запахом» — каннибализация средней полки.

**Сделать:** одна строка: Natural = натуральность + документы; Fleur/… = дизайн и аромат; HL = цена.

### B5. Политика тендеров с eco-знаком (P1)

Честный ответ про «без COSMOS сейчас» правильный. На тендере с обязательным знаком он = проигрыш или давление «ну напишите». Нужна политика **до** поля.

**Сделать:** «Тендер с обязательным COSMOS/аналог до знака — Natural в КП не ставим; HL или отказ.»

### B6. ToV sales-фразы платформы vs пульта (P1)

Платформа: «…не зависите от чужого бренда…»  
Пульт: сильнее про заботу (кожа + документы) и честные сертификаты.

Оба рабочих, но **два канона** сломают обучение продаж. Нужен один master-скрипт; второй — запасной.

### B7. Метрика гостя «натурально» — ловушка бренда (P1)

Гость не измеряет натуральность. Он мерит мягкость, запах, «не химия». Вопрос «натурально?» ловит желаемый ответ и eco-halo, не доказательство обещания.

**Сделать:** оставить «мягкость» и «не ощущается как дешёвая химия» как первичные; «натурально» — вторичный / качественный комментарий, не kill-метрика наравне с мягкостью. Иначе убьёте пилот опросом, а не продуктом — или наоборот зелёте ложным «71%».

### B8. Гостевой бренд в каналах отеля (P2)

Welcome-фраза есть. Нет носителей: ресепшен, горничная, QR на состав, мини-текст для wellness. Caregiver живёт в точках контакта.

**Сделать:** после пилота реестр 3–5 носителей — не медиаплан.

### B9. Иерархия на этикетке из платформы не перенесена (P2)

Платформа §8: Travel+ мелким · Natural читаемо · продукт крупно. В пульте — цвета и «простыми словами», иерархия имён не зафиксирована.

## 1.4 Red team: как бренд умрёт за 90 дней

1. Коммерция цитирует сценарий 78% на встрече → клиент просит «тот же аромат лён» → образца нет.  
2. Менеджер пишет в КП «российское производство» с платформы → завод тянет Китай → претензия и удар по честности.  
3. «Natural по цене HL» один раз согласовали «исключение» → полка схлопнулась.  
4. Тендер с COSMOS → дописали «в процессе сертификации» без заявки → аудит.  
5. Слепой тест в офисе на коллегах → в номере wellness-гостю «лён» кажется плоским.

## Вердикт Brand Manager

Рамка сильная. **Продуктовая честность отстаёт от текста платформы.** Следующий шаг — не ещё один слой поэзии, а: метод %, origin в границах, артефакты, один канон скрипта, правка метрики «натурально».

# 2. Отраслевой эксперт — досконально

*Контур: hotel amenities РФ / СНГ, закупка 3–4★ и eco/wellness, конкуренты HL / ЕТС / NS / MEZO.*

## 2.1 Что схвачено правильно

1. Двойной клиент (гость + закупщик) — базово для amenities.  
2. One-stop (косметика + тапочки + наборы) — реальный рычаг против «чистых натуралок».  
3. Отказ Natural = HL по цене — спасает маржу и полку.  
4. Честность про COSMOS на старте — в РФ eco-маркетинг без бумаг обычен; ваша позиция жизнеспособнее, если выдержать в поле.  
5. Диспенсер после флаконов — здраво (другой unit economics, монтаж, расход).  
6. СТМ отдельно от Natural — правильно; сети часто путают.

## 2.2 Критика по пунктам

### E1. Документы — язык завода, не учебник (P0)

«Декларация или СГР» без привязки к тому, **что Travel+ реально выдаёт на Hotel Line / Fleur сегодня**, путает коммерцию и закупщика. Для косметики в обороте в РФ критичен актуальный пакет под ваш юрконтур (что именно в папке у действующей линейки + что добавить под Natural).

**Сделать:** «Тот же класс документов, что на действующие линейки Travel+ + доп. лист состава под Natural»; шаблон копировать с реального пакета HL.

### E2. Происхождение и Китай — отраслевая мина (P0)

Повтор RF-1 с полевой стороны: eco/wellness 3–4★ часто спрашивают страну формулы и фасовки раньше, чем ISO. «Не знаем» внутри команды ок; **в рынке** «не знаем» = «скрываете». Импортный контракт без прозрачности бьёт сильнее отсутствия COSMOS.

**Сделать:** до выбора контура — запрет RU/«своё» в любых внешних текстах; в границах обещания — явный статус origin.

### E3. Условия поставки в GTM почти пустые (P0)

В КП сети смотрят: срок, кратность короба, замена брака, стабильность партии (цвет/запах от партии к партии), кто принимает претензию гостя, что с неликвидом при смене концепции этажа.

**Сделать:** в этапе 3 блок «условия поставки» (даже черновик с пометкой ops): lead time, MOQ, брак, претензии.

### E4. Слепой тест 15–20 — только скрининг (P1)

Ок как внутренний фильтр. Слабо как аргумент сети. Нет: критерии отбора респондентов, место (не офис), контроль (HL / ЕТС / без отдушки), правило победы.

**Сделать:** одностраничный протокол. Иначе «лён победил» в сценарии — анекдот.

### E5. One-stop надо доказать, не продекларировать (P1)

Сети часто **разводят** поставщиков косметики и текстиля/тапочек. Лозунг «один договор» без цифры из практики Travel+ — слабый козырь против ЕТС на полке.

**Сделать:** факт «сейчас X% клиентов берут косметику+тапочки» или честно «гипотеза, замерим на пилоте».

### E6. Персонал отеля (P1)

Горничные и ресепшен влияют на опыт и на то, дойдёт ли флакон до гостя «как задумано» (подмена, долив, срез этикетки).

**Сделать:** 1-pager для смены в плане запуска.

### E7. Экономика SKU amenities (P1)

Ориентир «рядом с ЕТС» без: граммовки (30 vs 25 мл), расхода на номер-ночь, доли мыла vs шампуня, боя/списания, логистики короба — прайс будет «от балды». Маржа «не хуже HL» при более дорогом сырье Natural без модели — самообман.

**Сделать:** до прайса — простая модель: COGS · объём · потери · целевая маржа; иначе этап 3 шаг «прайс» — театр.

### E8. Стабильность партии и сенсорика (P1)

Natural с «мягким» ароматом уязвим: партии «плывут», гость пишет «другое мыло». В рисках это слабо.

**Сделать:** риск «дрейф партии» + правило: эталонный образец на складе + допуск «как HL».

### E9. Сезонность и пилот (P2)

Пилот 12 недель может попасть в низкий сезон — повторный заказ «не потому что продукт плох». В критериях успеха/провала сезон не учтён.

**Сделать:** оговорка в этапе 5: учитывать загрузку объекта; не сравнивать январь с августом без поправки.

### E10. Конкурент NS как «дырявый склад» (P2)

Гипотеза сильная, но устаревает. Если NS стабилизирует поставки — дыра закрывается. Нужен запасной insight (контроль формулы / маржа / one-stop), не только «NS нет на складе».

## 2.3 Типичный закупщик на звонке (чеклист против пульта)

| Вопрос закупщика | Ответ пульта сейчас | Оценка |
|------------------|---------------------|--------|
| Какие документы в папке? | Список-намерение | Слабо |
| Страна производства? | Не знаем / платформа врёт RU | Провал |
| Срок поставки / MOQ? | Почти нет | Слабо |
| Чем не ЕТС? | Сенсорика + пакет | Ок как гипотеза |
| COSMOS? | Честно «нет сейчас» | Сильно, если удержать |
| Можно по цене HL? | Нет | Сильно |
| СТМ с нашим лого? | Другой проект | Сильно |
| Что если гостю не понравится запах? | Провал → этап 2 | Ок для вас; закупщику нужен обмен/замена |

## Вердикт эксперта

Рыночная логика схвачена. На живом тендере выиграет более скучный пакет с **понятными бумагами, origin, SLA**. Допилить заводской язык документов, происхождение, поставку, протокол теста и unit economics — иначе Natural останется красивым питчем Киришей для собеса, не полкой.

# 3. Product Manager — досконально

## 3.1 Что сильно как процесс

1. Этапы 0–6 с рубежами — управляемый контур, не слайд.  
2. Факт (0–2) / учебный сценарий (3–6) — заявлено; снижает (но не убивает) риск fiction→plan.  
3. Success **и** failure criteria пилота — правильный DoD поведения.  
4. Реестры рисков и «Не знаем» — прозрачный backlog неопределённости.  
5. Gate копирайтера — качество сдачи Human.  
6. Связь с шаблоном пульта 0–6 — переиспользуемость на другие линейки.

## 3.2 Готовность (scorecard)

| Область | Score | Комментарий |
|---------|-------|-------------|
| Problem discovery | 8/10 | Двойной клиент, конкуренты, гипотеза |
| Solution definition | 5/10 | Правила есть, продукт нет |
| Evidence / validation | 2/10 | Нет теста, нет образца, нет COGS |
| GTM readiness | 2/10 | Скрипты есть, поставка/прайс нет |
| Delivery system | 3/10 | Нет DoD, нет epic в очереди, нет RACI |
| Risk management | 7/10 | Риски названы; kill-criteria до сырья слабые |
| Metrics | 5/10 | Есть цели; метод опроса и n сырые; «натурально» спорно |
| Scope control | 6/10 | Диспенсер/COSMOS отложены по смыслу; не закреплены как OPTIONAL явно везде |

**Итог PM:** Discovery почти закрыт по рамке. Delivery не стартован. Ship запрещён.

## 3.3 Критика по пунктам

### P1. DoD снятия блокеров этапа 2 (P0)

«Рубеж продукта открыт» верно и бесполезно без Done.

| Артефакт | Владелец | Done когда |
|----------|----------|------------|
| Метод + целевой коридор % натуральности | технолог + бренд | подписано обеими сторонами |
| Пакет документов PDF (язык завода) | юрист / технолог | лежит в папке = шаблон HL+ |
| Origin: формула / фасовка | технолог + ops | статус зафиксирован; внешние формулировки согласованы |
| Протокол слепого теста + результат | бренд | победитель и правило победы записаны |
| Макет этикетки с «простыми словами» | дизайн + бренд | утверждён |

### P3. Нет владельца метрик и метода опроса (P1)

**Сделать:** владелец · метод · min n · частота · что делаем при n < порога (не считаем пилот «успехом по гостю»).

«Берём» на этапе 0 зафиксировано. Нет стоп-крана: ЕТС демпинг, NS закрыл складскую дыру, завод не тянет %/origin, COGS убивает «не хуже HL».

### P7. RACI на пилот (P1)

### P8. Зависимости и критический путь (P1)

Критический путь: метод% → формула → документы → образец → слепой тест → этикетка → COGS → прайс → пилот.  
Сейчас в тексте шаги этапа 3 идут почти линейно, но **формула и origin** не стоят как gate 0 перед тестом запаха (запах на сырой базе бессмысленен).

**Сделать:** явный gate: нет рабочей формулы/образца → слепой тест не стартуем.

### P9. Путаница целей документа (P1)

Документ одновременно: (a) dogfood пульта, (b) учебный кейс собеса, (c) заготовка живого запуска. Три цели = три стандарта строгости. PM должен выбрать primary audience в шапке.

**Сделать:** в шапке одна строка: «Primary: dogfood пульта + собес. Не live GTM.»

### P10. Нет Definition of Ready на этап 3 (P2)

DoD этапа 2 (P1 выше) + DoR этапа 3: коммерция не открывает витрину без чеклиста из P1.
