# Бренд-менеджмент: playbook (база)

**Владелец роли:** Brand Manager (`@role-brand-manager`) · сдача текста — Copywriter (`@role-copywriter`)  
**Обновлено:** 2026-07-27 (StoryBrand SB7 — обязательный слой коммуникации)  
**Фокус:** физ.товары, HoReCa / FMCG, Travel+  
**Язык:** простой русский

---

## 1. Главный принцип

Бренд — это не логотип.  
Это **система обещаний и опыта**, которая повторяется в продукте, цене, упаковке, сервисе и коммуникации.

Сначала фундамент → потом картинка.  
В тексте и питче: **клиент — герой, бренд — проводник** (StoryBrand).

---

## 2. «ДНК бренда» (Зарьков + Завражнов)

**Книга:** «ДНК бренда. Как построить сильный бренд в индустрии гостеприимства и не только»  
Борис Зарьков, Дмитрий Завражнов (Bookwings).  
Примеры из hospitality (White Rabbit Family), логика переносится на продукт/HoReCa.

### Порядок сборки (как в книге / обзорах)

1. **Базовые понятия** — что такое бренд, репутация, брендинг  
2. **Платформа бренда** — сущность, миссия, ценности, инсайты аудитории, обещание, философия, позиционирование  
3. **Личность и архетипы** — характер бренда (Герой, Наставник, Бунтарь…)  
4. **Позиционирование** — какое место в голове клиента  
5. **Айдентика** — визуал вытекает из характера, а не наоборот  
6. **Tone of Voice** — как бренд говорит  

**Инсайт авторов:** ДНК проявляется во всём — продукт, сервис, команда, коммуникация. Не «сначала лого».

### Мини-чеклист «ДНК» для Travel+ / линейки

- [ ] Зачем эта линейка существует (не «чтобы продавать шампунь»)  
- [ ] Кому обещаем (сеть 3★ / eco-отель / wellness)  
- [ ] Какое одно обещание  
- [ ] Чем не являемся (антипозиционирование)  
- [ ] Характер: спокойный заботливый / премиум-строгий / натуральный честный…  
- [ ] Как это видно на полке номера: флакон, запах, текст, цена  
- [ ] Как говорит продажа с закупщиком отеля

## 3. StoryBrand (Donald Miller) — обязателен для текстов

**Книга / метод:** *Building a StoryBrand* · каркас **SB7 / BrandScript**.  
Не заменяет ДНК и позиционирование — **собирает коммуникацию**: питч, скрипт sales, гостевая фраза, лендинг, собес.

### Правило

| Роль в истории | Кто |
|----------------|-----|
| **Герой** | Клиент (закупщик отеля и/или гость) |
| **Проводник (Guide)** | Бренд / линейка — эмпатия + авторитет |
| **Не герой** | Мы сами («мы крутые», «наш завод лучший» без пользы герою) |

В hotel amenities почти всегда **два BrandScript**: B2B (закупщик) и гостевой (или «отель помогает гостю»).

### Семь клеток BrandScript

1. **Герой** — кто хочет результата  
2. **Проблема** — внешняя (факт) · внутренняя (чувство) · философская (должно быть иначе)  
3. **Проводник** — «мы вас понимаем» + «вот почему нам можно доверять»  
4. **План** — 3 простых шага (не 12 фич)  
5. **Призыв** — прямой (пилот / образец) и мягкий (скачать пакет / сравнить)  
6. **Провал** — чего избегает герой, если не действует  
7. **Успех** — жизнь героя после  

### Мини-чеклист перед сдачей текста

- [ ] В первых фразах слышен **герой и его боль**, не завод  
- [ ] Бренд звучит как **проводник**, не как главный персонаж  
- [ ] Есть **план** (2–3 шага) или явный следующий шаг  
- [ ] Названы **провал** и **успех** (хотя бы намёком в питче)  
- [ ] Обещания не ломают границы продукта (origin, сертификаты, этикетка)

## 4. Международная классика (кратко)

| Инструмент | Зачем |
|:-----------|:------|
| **StoryBrand SB7** | Скрипт и питч: герой = клиент |
| **STP** | Сегмент → выбор → позиция |
| **Kapferer Prism** | Физика, характер, культура, отношения, отражение, самообраз |
| **Keller CBBE** | Пирамида: идентичность → смысл → реакция → связь |
| **Aaker** | Активы бренда: узнаваемость, воспринимаемое качество, ассоциации, лояльность |
| **Brand architecture** | Дом брендов: один masterbrand / линейки / endorsed (как NS у дистрибьютора) |
| **Jobs to be Done** | Какую «работу» нанимают продукт |
| **One-pager (P&G)** | Идея на 1 стр. для решения |

Российская практика hospitality + CPG: сильный акцент на **опыт в точке** (номер, полка) и на **доверие закупщика B2B**, не только на рекламу потребителю.

## 5. Слои бренда в hotel amenities

| Слой | Вопрос |
|:-----|:-------|
| Бренд производителя (Travel+) | Почему сети брать у вас, а не у ЕТС/MEZO |
| Линейка (Hotel Line / Fleur / Natural…) | Какой отель / какой чек |
| СТМ отеля | Логотип сети на вашей формуле |
| Чужой бренд в каталоге (Natura Siberica) | Вы канал, не владелец ДНК |

Не путать: продавать NS ≠ строить ДНК Travel+.

## 6. Рабочий цикл бренд-менеджера (физ.товар)

1. Insight клиента (гость + закупщик отеля)  
2. Позиция и обещание линейки  
3. **BrandScript StoryBrand** (закупщик + гость)  
4. Продукт / упаковка / цена под обещание  
5. Go-to-market (листинг, аргументы sales)  
6. Коммуникация (если есть бюджет)  
7. Замер: доля, повторный заказ, маржа, возвраты  
8. Реновация или снятие SKU  

Связка с China Logistics: обещание бренда не должно ломаться на качестве партии и сроке поставки.
