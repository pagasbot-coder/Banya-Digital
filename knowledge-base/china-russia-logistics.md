## 1. Карта пути товара

```
Завод в Китае
  → склад / порт / аэропорт в Китае
  → международная перевозка
  → граница / таможня РФ (или ЕАЭС)
  → склад в РФ (напр. Кириши / СПб)
```

Цена «на заводе» ≠ цена «на твоём складе».  
Всегда считай **полную стоимость прихода**.

---

## 2. Способы перевозки

| Способ | Когда брать | Плюсы | Минусы |
|:-------|:------------|:------|:-------|
| **Море, целый контейнер (FCL)** | Большая серия, не срочно | Дешевле за кг/м³ | Долго (часто недели+) |
| **Море, сборный (LCL)** | Средний объём, не на весь контейнер | Не ждёшь полный контейнер | Дороже FCL за единицу, больше перевалок |
| **Ж/д контейнер** | Средний срок, стабильный поток | Быстрее моря, предсказуее | Не для всего; зависит от маршрута |
| **Авиакарго** | Образцы, срочный довоз | Быстро | Дорого; лимиты по опасным грузам/жидкостям |
| **Авто / мультимодалка** | Часть плеча после границы или спецсхемы | Гибкость «до двери» | Цена и срок зависят от плеча |
| **Карго-агрегатор / «карго»** | Мелкие партии, частые отправки | Удобно через посредника | Нужно понимать, что в цене и кто отвечает за риск |

**Образцы** — чаще авиа или карго мелкой партией.  
**Серия amenities** — чаще море (FCL/LCL) или ж/д.

## 3. Incoterms простыми словами

Кто платит и кто несёт риск на каком этапе.

| Термин | Смысл одной фразой |
|:-------|:-------------------|
| **EXW** | Забираешь сам с завода. Максимум головной боли на тебе. |
| **FOB** | Завод довёз до порта и погрузил на судно. Дальше — ты/твой логист. |
| **CFR / CIF** | Продавец оплатил море до порта назначения (+ в CIF страховку). Таможня РФ и довоз — обычно на тебе. |
| **CPT / CIP** | Похоже на доставку до согласованного пункта; смотри риск и страховку в договоре. |
| **DAP** | Довезли до места (например склад), пошлины обычно на покупателе. |
| **DDP** | «До двери» с пошлинами — продавец закрывает почти всё. Дорого и не все реально умеют в РФ. |

**Для сравнения заводов:** котируй **FOB**.  
**Логистику до Киришей** считай отдельной строкой.

## 4. Термины — Китай / перевозка

| Термин | Простыми словами |
|:-------|:-----------------|
| **MOQ** | Минимальный заказ |
| **Lead time** | Срок производства / готовности |
| **FCL** | Целый контейнер только твой |
| **LCL** | Сборный контейнер, место рядом с чужим грузом |
| **CBM** | Кубический метр — так считают объём |
| **Gross weight / Net weight** | Вес с упаковкой / без |
| **Packing list** | Список мест: что в каких коробах |
| **Commercial invoice** | Счёт для таможни и оплаты |
| **Bill of Lading (B/L)** | Морской коносамент — документ на груз |
| **AWB** | Авианакладная |
| **HS code** | Код товара для таможни |
| **Trade Assurance / эскроу** | Защита сделки на платформе (не magия) |
| **Forwarder / экспедитор** | Компания, которая организует перевозку |
| **Consol / сборка** | Сводный груз мелких отправителей |

---

## 5. Термины — Россия / ввоз

| Термин | Простыми словами |
|:-------|:-----------------|
| **ТН ВЭД / HS** | Код классификации товара |
| **Декларация** | Таможенное оформление ввоза |
| **Пошлина / НДС на ввоз** | Платежи при импорте (считает брокер по коду) |
| **Брокер** | Таможенный представитель |
| **ЕАЭС** | Таможенный контур РФ + партнёры |
| **Сертификат / декларация соответствия** | Допуск товара на рынок (для косметики — критично) |
| **Маркировка** | Требования к этикетке / «Честный знак» где применимо |
| **СВХ** | Склад временного хранения на таможне |
| **Инвойсная стоимость** | Стоимость для таможни — должна быть согласована с реальностью |

## 6. Полная себестоимость прихода (скелет)

```
FOB (или цена завода)
+ довоз по Китаю до порта/аэропорта (если не в цене)
+ фрахт / авиа / ж/д
+ страховка
+ услуги экспедитора / карго
+ таможня (пошлина, НДС, брокер)
+ сертификаты / испытания (если нужны)
+ довоз до склада (Кириши)
+ комиссия посредника
+ запас на брак / пересорт
= цена на складе
```

## 7. Вопросы экспедитору / посреднику (чек-лист)

1. Способ: море FCL/LCL / ж/д / авиа / карго?  
2. Срок door-to-door или port-to-door?  
3. Что входит в ставку?  
4. Кто делает экспорт в Китае и импорт в РФ?  
5. Нужны ли от нас: инвойс, packing list, состав, сертификаты?  
6. Ограничения по косметике / жидкостям / батарейкам?  
7. Куда приёмка: СПб / Москва / Кириши?  
8. Страховка — есть / лимит / франшиза?
